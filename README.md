# taxila3d-fixtures

Test fixtures for [`taxila3d-rust`](https://github.com/CoEdge/taxila3d-rust) —
curated 3D mesh corpus consumed as a git submodule.

## What's here

```
obj/    ~10 small OBJ meshes from alecjacobson/common-3d-test-models + Stanford bunny
stl/    ~20 procedural STLs (boxes, spheres, tori, ...) generated by refresh_stl_subset.py
        — both binary + ASCII variants, no third-party content
gltf/   ~10 glTF samples from KhronosGroup/glTF-Sample-Assets
        (mixed .gltf+.bin, .gltf-Embedded data-URI, and .glb binary container)
step/   11 procedural STEP (ISO 10303-21) B-rep parts generated by
        refresh_step_subset.py — no third-party content
scripts/ refresh_*.py — regenerate each corpus
```

Unlike the mesh corpora, `step/` is chosen for *importer edge cases*
rather than shape variety — each file targets a specific failure mode
(see the `purpose` column of `step/CREDITS.csv`). The ones worth knowing:

| File | Why it exists |
|---|---|
| `cylinder_seamless.step` | Lateral face bounded only by its two rim circles — **no seam edge**. Real CAD writers emit this constantly; in UV the loops wind a full period and cannot close, so the importer must synthesize a seam. |
| `sphere_poles.step` | One face whose entire boundary is two pole `VERTEX_LOOP`s — no edges at all. |
| `cone_seamless.step` | Full-period base circle closed by an apex `VERTEX_LOOP` (parametric degeneracy). |
| `torus_seamless.step` | Periodic in *both* directions. |
| `plate_with_hole.step` | Inner loops, each a single closed circle edge. |
| `tetra_foreign_dialect.step` | Exponent floats, a non-unit `VECTOR` magnitude (file parameterization disagrees with the kernel's), reversed `.F.` `FACE_BOUND`. |
| `assembly_two_parts.step` | `NEXT_ASSEMBLY_USAGE_OCCURRENCE` tree with an `ITEM_DEFINED_TRANSFORMATION`. |
| `hybrid_box.step` | AP242 hybrid — B-rep plus a linked `TESSELLATED_SHAPE_REPRESENTATION`. |
| `box_ap2{03,14,42}.step` | Identical geometry across all three schemas. |

Total size: < 80 MiB (target). All refresh scripts are stdlib-only Python.

## How to use (downstream consumers)

In `taxila3d-rust` this lives at `tests/data/corpus/` via:

```
git submodule add https://github.com/CoEdge/taxila3d-fixtures.git tests/data/corpus
```

For an existing clone:
```
git submodule update --init tests/data/corpus
```

## Refreshing the corpus

When an upstream source drifts (file rename, model added/removed) or we
want to expand coverage:

```
python scripts/refresh_obj.py            # ~10 OBJs (downloads from GitHub raw)
python scripts/refresh_gltf.py           # ~10 glTF entries (downloads from GitHub raw)
python scripts/refresh_stl_subset.py     # ~20 procedural STLs (no network)
python scripts/refresh_step_subset.py    # 11 procedural STEP parts (no network)
git add obj gltf stl step
git commit -m "fixtures: refresh corpus"
git push
```

Then in `taxila3d-rust`, bump the submodule pin:
```
cd tests/data/corpus && git pull origin main && cd ../../..
git add tests/data/corpus
git commit -m "test: bump fixtures submodule"
```
